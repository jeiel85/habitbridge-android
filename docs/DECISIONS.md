# 결정 기록 (되돌리기 어려운 결정만)

형식: 배경 → 선택지 → 결정 → 근거 → 되돌릴 때의 비용.

## D-001 · 포그라운드 감지는 UsageStatsManager 주 경로, 접근성 서비스는 선택 — 2026-09-10

- **선택지**: (A) UsageStats 폴링 / (B) AccessibilityService / (C) 로컬 VPN 프로필(Opal 방식).
- **결정**: A 주 경로 + B 선택 경로. C는 채택하지 않음.
- **근거**: Google Play는 접근성 API를 접근성 목적 외로 쓰는 앱에 선언 양식과 심사를 요구하고 거절 사례가 많다. A는 디지털 웰빙 용도로 허용되며 지연 ~1초는 "멈춤"이라는 제품 목적에 충분하다. C는 배터리·트래픽 우려(원본 §1.3 4번)와 정면 충돌한다.
- **되돌릴 비용**: 중간. 감지 어댑터 인터페이스(`ForegroundEvent`) 뒤에 두어 교체 가능하게 설계한다.

## D-002 · INTERNET 권한을 넣지 않는다 (서버 없음, 크래시 SDK 없음) — 2026-09-09 (원본 유지, 범위 명확화)

- **결정**: 매니페스트에 `INTERNET` 없음. 결제는 Play Billing(Play Store 앱이 통신), 진단은 로컬 로그 파일.
- **근거**: "100% 로컬"은 마케팅 문구가 아니라 검증 가능한 약속이어야 한다. 권한이 없으면 사용자가 스스로 확인할 수 있다.
- **되돌릴 비용**: 매우 높음(신뢰). 되돌리지 않는 전제로 설계한다.

## D-003 · 정책 엔진은 순수 모듈(`:core:policy` ↔ `src/engine.js`), 시각은 항상 인자로 받는다 — 2026-09-10

- **선택지**: 서비스 코드 안에 규칙 산재 / 순수 모듈 + 시각 주입.
- **결정**: 순수 모듈. `decide(state, pkg, now)`처럼 `now`를 인자로 받고 `Date.now()`를 내부에서 호출하지 않는다.
- **근거**: 자정 경계·취침 wrap·쿨다운 같은 시간 규칙은 테스트 없이 맞추기 어렵다. 웹 프로토타입과 Kotlin이 같은 테스트 벡터를 공유하려면 시각 주입이 필수다.
- **되돌릴 비용**: 높음(테스트 전략 전체). 유지한다.

## D-004 · 우회는 처벌하지 않는다: 쿨다운 10분 + 시간당 상한 6회 초과 시 SOFT 완화 — 2026-09-10

- **선택지**: 열수록 길어지는 지연(ScreenZen식) / 우회 시 더 강한 마찰 / 우회 후 조용히 두기.
- **결정**: 우회 후 10분 통과, 시간당 6회 넘으면 오히려 완화.
- **근거**: 원본이 지목한 2주 삭제 원인이 마찰 피로다. 마찰이 "멈춤"으로 작동하지 않는 상황에서 더 세게 막는 것은 권한 해제로 이어진다. 제품의 목적은 차단이 아니라 의도적 선택이다.
- **되돌릴 비용**: 낮음(수치). 단, "처벌하지 않는다"는 원칙은 P2 데이터 없이 뒤집지 않는다.

## D-005 · 절약 시간은 로그에 저장하지 않고 설정값으로 파생 계산 — 2026-09-10

- **결정**: `savedTimeSeconds` 컬럼 제거, `savedMinutesPerAvoid`(기본 5) × (스왑 + 홈 복귀).
- **근거**: 추정치를 사실처럼 저장하면 설정을 바꿀 때 과거 통계가 뒤틀린다. 파생값은 언제든 재계산된다.
- **되돌릴 비용**: 낮음.

## D-006 · 공유 카드에는 앱 이름·메모·감정을 넣지 않는다 — 2026-09-10

- **결정**: 카드는 점수·절약 분·비율·연속 일수·유형 막대만.
- **근거**: 카드는 SNS로 나간다. "인스타그램 47회 개입"이나 감정 기록은 공유 의도와 무관하게 새는 정보다.
- **되돌릴 비용**: 낮음(레이아웃). 원칙은 유지.

## D-007 · 배포·저장소: 문서 + 웹 프로토타입은 GitHub Pages(`main` 루트), 안드로이드 코드는 같은 저장소의 `android/` 하위에 추가 예정 — 2026-09-10

- **근거**: 설계서·엔진·테스트 벡터·앱 코드가 한 곳에 있어야 매핑(부록 C)이 살아 있다. Pages는 빌드 없이 루트 서빙.
- **되돌릴 비용**: 낮음.
