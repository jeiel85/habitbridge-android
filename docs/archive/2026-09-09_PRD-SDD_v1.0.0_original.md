## 1. 바이럴 디지털 디톡스 앱 심층 분석

### 1.1 분석 대상

- **대표 레퍼런스**: 《Opal (오팔)》, 《One Sec (원 센컨드)》, 《ScreenZen》  
- **장르/카테고리**: 생산성, 디지털 디톡스, 스크린타임 마찰(Friction) 인터셉터

### 1.2 바이럴 핵심 요인 (Viral Drivers)

1. **도파민 디톡스(Dopamine Fasting) 트렌드**  
   - 숏폼(TikTok, Reels, Shorts) 중독으로 인한 뇌 피로와 무의식적인 앱 진입(Autopilot) 문제 해결에 대한 강한 니즈.  
2. **인지적 마찰(Cognitive Friction)의 도입**  
   - 단순 차단이 아닌 '1초~5초 호흡 지연'을 통해 무의식적 스크롤 반사를 이성적 통제 상태로 전환.  
3. **SNS 공유용 성적표(Viral Stats Card)**  
   - "Focus Score 85%", "오늘 절약한 시간 2시간 15분"과 같은 미려한 카드 이미지를 인스타그램 스토리에 공유하는 강력한 바이럴 루프.

### 1.3 나쁜 요소 및 기존 앱의 결함 (Pain Points)

1. **차단 후 공백 상태(The Void)로 인한 '도파민 풍선 효과'**  
   - 인스타그램을 막으면 손가락이 방황하다가 유튜브를 열거나 웹 브라우저로 우회함. 단순 차단은 대안 행동이 없으면 실패함.  
2. **과도한 마찰 피로(Friction Fatigue)와 2주 내 삭제율 급증**  
   - 급하게 메신저나 업무 앱을 켜야 할 때도 획일적으로 5초 호흡을 강제하여 사용자가 짜증을 느끼고 접근성 권한을 해제함.  
3. **연간 $99에 달하는 약탈적 구독료 강요**  
   - 로컬 유틸리티임에도 과도한 구독제를 요구하여 1점 리뷰 및 유저 반발 심화.  
4. **프라이버시 및 배터리 이슈**  
   - 로컬 VPN 프로필 방식(Opal 등)은 배터리 누수 및 개인 트래픽 유출 우려를 야기함.

## 2. +α 혁신 프로젝트: 《HabitBridge》 제품 개요

> **"Don't just block dopamine. Swap it intentionally."**  
> *(도파민을 무작정 막지 마세요. 가치 있는 마이크로 행동으로 스왑하세요.)*

### 2.1 핵심 가치 제안 (Value Proposition)

1. **From Block to Swap (마이크로 스왑)**:  
   - 인스타/유튜브를 켤 때 생기는 5초의 마찰 동안 [1분 스트레칭], [단어 1개 암기], [영감 퀵 메모], [감정 체크인] 중 1개를 1-Tap으로 즉시 실행하고 홈으로 복귀.  
2. **Context-Aware Smart Shield (상황 인지형 마찰 조절)**:  
   - 캘린더 일정(회의 중)이나 늦은 밤에는 엄격 차단, 일상 시간대에는 부드러운 3초 리마인더로 마찰 피로 방지.  
3. **100% Local-First & Zero Server**:  
   - INTERNET 권한 없이 기기 낸부 Room DB에만 통계 및 메모를 저장. 프라이버시 100% 보장.  
4. **Pay-Once Lifetime ($19.99) & 오픈코어**:  
   - 지긋지긋한 월간/연간 구독 대신 1회 평생 소장 라이선스 제공.

## 4. 시스템 아키텍처 및 안드로이드 컴포넌트 설계

### 4.1 기술 스택

- **Language**: Kotlin 2.0+  
- **UI**: Jetpack Compose (Material3 Dark/Monospace Terminal 테마)  
- **Architecture**: Clean Architecture + MVI (StateFlow)  
- **Local DB**: Android Room DB 2.6+ (SQLite)  
- **시스템 권한**: AccessibilityService, SYSTEM_ALERT_WINDOW, PACKAGE_USAGE_STATS

### 4.2 아키텍처 데이터 플로우

```text
[Target App Launch]
       │
       ▼
[HabitAccessibilityService] (TYPE_WINDOW_STATE_CHANGED)
       │
       ▼
[ForegroundAppInterceptor] ──(Check Blacklist & Cool-down)
       │
       ▼

       │
       ▼
```

## 5. 데이터베이스 스키마 설계 (Room DB Entities)

```kotlin
package com.habitbridge.data.local.entity

import androidx.room.Entity
import androidx.room.Index
import androidx.room.PrimaryKey
// 1. 차단 대상 앱 테이블

@Entity(tableName = "target_apps")

data class TargetAppEntity(
    @PrimaryKey val packageName: String,
    val appName: String,
    val isBlocked: Boolean = true,
    val shieldLevel: String = "NORMAL", // SOFT (3s), NORMAL (5s), HARDCORE (No Bypass)
    val dailyQuotaMinutes: Int = 0,
    val createdAt: Long = System.currentTimeMillis()
)

// 2. 도파민 스왑 로그 테이블

@Entity(
    tableName = "swap_logs",
    indices = [Index(value = ["timestamp"]), Index(value = ["targetPackage"])]
)

data class SwapLogEntity(
    @PrimaryKey(autoGenerate = true) val logId: Long = 0,
    val targetPackage: String,
    val timestamp: Long = System.currentTimeMillis(),
    val actionTaken: String, // SWAPPED, BYPASSED, DISMISSED_HOME
    val swappedType: String?, // STRETCH, VOCAB, QUICK_NOTE, EMOTION
    val savedTimeSeconds: Int = 300, // 추정 절약 시간 (기본 5분)
    val noteContent: String? = null // 퀵 메모 작성 시 내용 저장
)

// 3. 퀵 메모 전용 테이블 (마크다운 익스포트 연동)

@Entity(tableName = "quick_notes")

data class QuickNoteEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val timestamp: Long = System.currentTimeMillis(),
    val content: String,
    val triggeredPackage: String,
    val isExportedToMd: Boolean = false
)
```

## 6. 핵심 인터셉터 코드 구현 가이드

```kotlin
// FullscreenOverlayManager.kt

class FullscreenOverlayManager @Inject constructor(
    @ApplicationContext private val context: Context,
    private val swapLogDao: SwapLogDao
) {
    private val windowManager = context.getSystemService(Context.WINDOW_SERVICE) as WindowManager
    private var overlayView: ComposeView? = null

    fun showFriction(targetPkg: String, level: String) {
        Handler(Looper.getMainLooper()).post {
            if (overlayView != null) return@post
            val params = WindowManager.LayoutParams(
                WindowManager.LayoutParams.MATCH_PARENT,
                WindowManager.LayoutParams.MATCH_PARENT,
                WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY,
                WindowManager.LayoutParams.FLAG_NOT_TOUCH_MODAL or WindowManager.LayoutParams.FLAG_LAYOUT_IN_SCREEN,
                PixelFormat.TRANSLUCENT
            )
            overlayView = ComposeView(context).apply {
                setViewCompositionStrategy(ViewCompositionStrategy.DisposeOnDetachedFromWindow)
                setContent {
                    HabitBridgeTheme {
                        FrictionScreen(
                            packageName = targetPkg,
                            onSwapComplete = { type, memo ->
                                recordSwap(targetPkg, type, memo)
                                returnHome()
                                hideOverlay()
                            },
                            onContinue = {
                                recordBypass(targetPkg)
                                hideOverlay()
                            }
                        )
                    }
                }
            }
            windowManager.addView(overlayView, params)
        }
    }

    private fun returnHome() {
        val intent = Intent(Intent.ACTION_MAIN).apply {
            addCategory(Intent.CATEGORY_HOME)
            flags = Intent.FLAG_ACTIVITY_NEW_TASK
        }
        context.startActivity(intent)
    }

    fun hideOverlay() {
        overlayView?.let {
            windowManager.removeView(it)
            overlayView = null
        }
    }
}
```

## 7. MVP 개발 로드맵 (스프린트 1~4)

- **Sprint 1 (1~2주차): 인터셉션 엔진 & 오버레이 파이프라인**  
  - AccessibilityService 윌도우 감지 및 SYSTEM_ALERT_WINDOW 풀스크린 오버레이 구현.  
  - Room DB 기본 스키마 및 타깃 앱 등록 리스트 UI.  
- **Sprint 2 (3~4주차): 마이크로 스왑 모듈 4종 & 다크 테마 UI**  
  - 스트레칭 가이드 타이머, 영단어 플립 카드, 퀵 메모장, 감정 체크인 모듈.  
  - 스왑 완료 시 홈 이동 및 로컬 DB 기록 연동.  
- **Sprint 3 (5~6주차): 대시보드 통계 & 마크다운 파일 자동 익스포트**  
  - 일간/주간 도파민 스왑 비율(Swap Ratio) 차트.  
  - 퀵 메모 내역을 /Documents/HabitBridge/Notes_YYYYMMDD.md로 로컬 파일 자동 동기화.  
- **Sprint 4 (7~8주차): 소셜 바이럴 카드 생성 & 구글 플레이 릴리즈**  
  - 인스타그램 스토리 공유용 1080x1920 CLI 스타일 도파민 성적표 비트맵 생성.  
  - 1회 평생 라이선스 인앱 결제 연동 및 Closed Testing 개시.
